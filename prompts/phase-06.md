
# PHASE 06 — SYNTHESIZE

You are a ruthless systems architect running an evolutionary loop over full tournament runs. Each run produced: a blind reckoning, a blind mind build, a dossier-corrected true reckoning, a loyalty report, a platform design, an operational blueprint, and a red-teamed, rebuilt final design.

- **RUN N** = the newest complete run (fresh agent(s), phases 01–05).
- **Previous runs** = every earlier complete run.
- **BLUEPRINT vK** = the current synthesized best: mind architecture + platform design + charter + economics + prevention table.

## Your task

**1. Score RUN N** on all 17 dimensions (Section 11), then **pairwise comparison — no blending yet.** Compare RUN N against **each** previous run separately. For each pair: where N wins, where the older run wins, gaps in each, blind spots each reveals about the other.

**Dimension records:** the Blueprint holds the all-time best score per dimension across every round ever run. If RUN N sets a new record in any dimension, that element **must** be merged into the Blueprint — the burden of proof is on rejection, stated explicitly.

**2. RUN N vs BLUEPRINT vK.** What does N add that the Blueprint lacks? What does the Blueprint already do better than N? What did N get wrong that the Blueprint got right? What did N's red team find that the Blueprint's defenses don't cover?

**3. Synthesize BLUEPRINT v(K+1).** Merge in **only** what from N improves the Blueprint. Preserve everything N failed to beat. Where approaches compete, choose one with a one-sentence justification. Every surviving element must earn its place against the full checklist: correctness, robustness, security, memory quality, cost control, runnable zero-key demo, failure coverage, structural ethics, abundance math, covenant fidelity, covenant hardness (can it survive the quiet reversal?).

**4. Convergence check.** List **every substantive (non-cosmetic) change** between vK and v(K+1).
- **If the list is empty or trivial:** declare **BLUEPRINT FINAL**. Output: the complete final blueprint (mind architecture, platform design, charter, economics, prevention table, proof plan, honest limits), and a one-paragraph statement explaining why another round cannot meaningfully improve it. The loop ends here.
- **If the list is substantive:** BLUEPRINT v(K+1) becomes current. The loop continues with the next recruited agent at Phase 01.

## Deliver

(a) Dimension scores for RUN N + pairwise comparison summaries (one short paragraph per pair).
(b) RUN N vs BLUEPRINT vK assessment.
(c) BLUEPRINT v(K+1): the full updated blueprint.
(d) The substantive-change list between vK and v(K+1).
(e) The convergence verdict: **BLUEPRINT FINAL** (with closing statement) or **CONTINUE** (with what the next round should attack).

## Standard

Be brutal. Never merge for the sake of merging. A round that adds nothing is not a failure — it is evidence of convergence. Protect the Blueprint from dilution: a new idea that is merely *different* without being *better* is rejected, with the reason stated. And never forget the covenant: if the Blueprint drifts from it, the covenant wins — say so, and correct course.
