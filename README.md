# thedailystoke

## 10-4 Vault

A private cloud on hardware you own — photos, files, notes, and a full iPhone
replica. Encrypted on your machine before it leaves it, backed up off-site to
storage that cannot read a word of it, reachable from anywhere over Tailscale
and nowhere else.
